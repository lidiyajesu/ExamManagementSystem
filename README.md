# Automated Examination Hall Allocation and Management System

## Project Description
This project is developed to automate examination hall allocation and management.

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- QR Code

## Features
- Student data management
- Hall capacity checking
- Automatic hall allocation
- Seat allocation
- QR code generation
- Attendance management
- Examination reports

## How to Run
1. Install Python.
2. Install required packages.
3. Configure MySQL database.
4. Run `app.py`.
5. Open the application in a web browser.

## Project Structure
- `app.py` – Main Flask application
- `templates/` – HTML pages
- `static/` – CSS and other static files
